# Repository instructions

## UI pull requests

- Every PR with user-visible UI changes must include clearly labeled **Before** and **After** screenshots in its description.
- Capture screenshots directly from running copies of the app built from the PR base and proposed branch. Generated images, offscreen renders, and mockups do not satisfy this requirement.
- Use matching window size, appearance, and comparable app state so reviewers can compare the affected view.
- Inspect the screenshots before posting, and refresh them whenever the UI changes during review.

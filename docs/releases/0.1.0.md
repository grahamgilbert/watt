# Watt 0.1.0 prerelease

The first Watt release brings a compact macOS menu bar monitor together with a local performance timeline.

- Configurable menu bar meters and numeric readings for CPU, memory, and network activity.
- A visual popup with CPU/memory history, upload/download graphs, estimated battery flow, and busiest-process activity bars.
- Process Explorer combines live and historical CPU, physical footprint, footprint growth, disk reads/writes, and observed parent relationships.
- Local SQLite recording with bounded retention, explicit gaps, historical snapshots, and interval summaries.
- Corrected used-memory accounting excludes reclaimable file cache, bringing the definition in line with Activity Monitor's app + wired + compressed memory. Older recorded estimates remain labeled as legacy data.
- Sparkle update checking, signed stable/prerelease feeds, manual checks, and an optional prerelease channel.
- A new native Watt app icon.

Requires macOS 14 or later. The universal app supports Apple Silicon and Intel Macs.

## Prerelease limitations

Battery flow is an estimate of charge/discharge, not total system consumption on external power. CPU/GPU/SoC power, temperatures, privileged collection, and automatic explanations are not implemented yet. Protected processes may be unavailable, polling can miss short-lived processes, and per-process footprints are not additive. Live CPU values and Activity Monitor can differ due to sampling intervals; per-process CPU uses 100% per core.

This release establishes the Sparkle update baseline. Install it manually once; later signed releases can update through Watt. Enable Include prerelease versions in the popup's Updates section to receive prerelease updates.

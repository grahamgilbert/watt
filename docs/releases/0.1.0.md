# Watt 0.1.0 prerelease

The first Watt release brings a compact macOS menu bar monitor together with a local performance timeline.

- Configurable menu bar meters and numeric readings for CPU, memory, and network activity.
- A visual popup with CPU/memory history, upload/download graphs, estimated battery flow, and busiest-process activity bars.
- Process Explorer combines live and historical CPU, physical footprint, footprint growth, disk reads/writes, and observed parent relationships.
- Local SQLite recording with bounded retention, explicit gaps, historical snapshots, and interval summaries.
- Corrected used-memory accounting excludes reclaimable file cache, bringing the definition in line with Activity Monitor's app + wired + compressed memory. Older recorded estimates remain labeled as legacy data.
- Sparkle update checking, signed stable/prerelease feeds, manual checks, and an optional prerelease channel.
- Per-process estimated CPU watts and historical joules, with explicit coverage and unavailable readings; Applications mode groups observed app helpers.
- Corrected process CPU timing on Apple Silicon, with older CPU history marked as legacy measurements.
- A drag-and-drop popup layout editor: move available tiles onto the preview, drag back to hide, reorder, and choose two to six columns. Square tiles are the default; full-width tiles are optional.
- Unified Preferences for appearance, sample interval, popup layout, and Sparkle updates.
- Appearance migration from prototype builds and simplified popup actions.
- A new native Watt app icon.

Requires macOS 14 or later. The universal app supports Apple Silicon and Intel Macs.

## Prerelease limitations

Battery flow is an estimate of charge/discharge, not total system consumption on external power. System-wide CPU/GPU/SoC power, temperatures, privileged collection, and automatic explanations are not enabled in this prerelease. Process CPU watts are CPU-only estimates, not Activity Monitor’s unitless Energy Impact score. The experimental privileged collector is not bundled or registered. Protected processes may be unavailable, polling can miss short-lived processes, and per-process footprints are not additive. Live CPU values and Activity Monitor can differ due to sampling intervals; per-process CPU uses 100% per core.

This release establishes the Sparkle update baseline. Install it manually once; later signed releases can update through Watt. Enable Include prerelease versions in Preferences to receive prerelease updates.

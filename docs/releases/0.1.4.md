# Watt 0.1.4 prerelease

This prerelease adds focused tile details and recorded per-process network activity.

- Consolidates the default dashboard into CPU, Memory, Network, Disk activity, Energy and Battery tiles. Existing custom layouts retain their column count, order and hidden categories; dedicated tiles remain available in the layout editor.
- Opens larger graphs and process/application breakdowns inside the menu bar popup. Inspect a recorded time, return with Back or Escape, or continue in Process Explorer with the same range, grouping and metric. Reopening the popup starts at the overview.
- Records per-process external TCP/UDP byte counts for both popup details and Explorer history. Preferences controls recording; connection addresses and payloads are not recorded. Process samples show their own interval, age and coverage because attribution can lag physical-interface totals.
- Adds combined download/upload and disk read/write summaries with explicit units, plus a saved CPU-power or Energy Impact summary choice for the Energy tile.
- Bounds and cancels detail-history reads when the detail closes. The existing CI CPU/memory regression gate remains in place, and a live collector test checks for excess CPU use and child-process cleanup.

## Prerelease limitations

Per-process network history is available only for newly recorded samples. Unmatched or unavailable readings remain unavailable; process attribution can differ from physical-interface totals. A busy detail range may exceed its memory budget; use Process Explorer for a larger investigation.

CPU power is an estimate, while Apple's Energy Impact is a separate unitless measurement requiring the optional approved collector. The signed helper still needs end-to-end validation in an approved installation. Hardware temperatures and whole-device CPU/GPU/SoC power are not included.

CI rendering benchmarks and short local recorder measurements do not establish long-run recorder/helper overhead or battery-life impact.

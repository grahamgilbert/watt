# Watt 0.1.2 prerelease

This prerelease reduces Watt’s background work and improves Process Explorer rendering.

- Launches directly into the menu bar and constructs inspection windows on demand. Hidden popup/Explorer views and closed settings/layout views release their content.
- Samples at the configured interval instead of waking every second.
- Keeps a smaller live process cache and restores less data at startup. Older retained detail remains available through SQLite history.
- Draws Explorer graphs with native Quartz, caches graph projections and makes the shared time cursor easier to see.
- Reduces repeated process-energy lookups, SQLite queries and helper watchdog work. Energy collection keeps the same cadence and signed connection checks.
- Adds CPU and memory regression checks on GitHub-hosted macOS runners, with repeated baseline comparisons and saved results.

## Prerelease limitations

The CI performance workload covers Explorer rendering and data processing. It does not establish battery-life savings, overnight memory behavior or total recorder/helper overhead.

Energy Impact still requires an approved, signed collector; check its status in Preferences → Energy Impact. Its unitless process scores remain separate from CPU watts and Activity Monitor’s application totals.

Hardware temperatures and system-wide CPU/GPU/SoC power are not included.

# Watt 0.1.3 prerelease

This prerelease adds Open at login and improves visibility into protected system and security processes.

- Adds Open at login in Preferences → General, enabled on the first launch of an eligible signed app. Later opt-outs in Watt or macOS System Settings are preserved.
- Keeps system extensions and security daemons visible when macOS denies resource access. Restricted readings show a lock and unavailable values instead of zeros.
- Extends the approved, signed collector with native per-process CPU, physical-footprint, disk, CPU-energy and wakeup counters where macOS permits access.
- Records process owner, metric source and unavailable footprints in history. Graphs and interval summaries preserve missing readings.
- Reuses selected Explorer snapshots and byte formatting, and saves diagnostic profiles when CI performance checks fail.

## Prerelease limitations

If an existing collector cannot provide protected-process metrics, use **Reinstall collector…** in Preferences → Energy Impact. Administrator approval may be required. Some protected processes may remain unavailable even with the collector, and public fallback names may be truncated. The updated privileged collector still needs end-to-end validation in an approved signed installation.

Older Watt versions may not read new history frames containing unavailable footprints.

Native login registration, toggling, relaunch persistence and System Settings opt-out were verified locally with a signed app. A full logout/login cycle has not been performed.

Hardware temperatures and system-wide CPU/GPU/SoC power are not included. CI rendering measurements do not establish battery-life savings or total recorder/helper overhead.

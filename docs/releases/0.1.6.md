# Watt 0.1.6 prerelease

Fixes Live Process Explorer showing only a few minutes of activity on a longer timeline. Explorer now loads the selected interval from recorded SQLite history, then adds incoming samples. Existing recordings remain intact.

The date field follows the displayed Live window until you edit it. Earlier, Later and Inspect use that window, and inspecting a recorded moment keeps the timeline and process details fixed at that time.

History is loaded only while Explorer is visible. Closing it cancels outstanding reads and releases the working set; the background recorder cache stays unchanged.

Detailed history retains limits of 1,500 samples and 96 MiB per read, plus 250,000 visible telemetry rows. Large intervals on busy devices can exceed these limits and now show an explicit message. Use shorter intervals to navigate those recordings; this release does not add unlimited multi-hour detail views.

Includes the dashboard details, per-process network history and larger Back control from earlier prereleases. See the [0.1.4 prerelease notes](https://github.com/grahamgilbert/watt/releases/tag/v0.1.4) for collection coverage and other limitations.
